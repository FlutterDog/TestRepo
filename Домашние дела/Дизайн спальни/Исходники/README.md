# Исходники

В этой папке должны храниться исходные панорамные фотографии и очищенные опорные изображения комнаты. На момент создания проектного README исходные бинарные фотографии из рабочего диалога не были перенесены через GitHub-коннектор; папка оставлена подготовленной для последующего добавления без изменения структуры проекта.

Рекомендуемые имена файлов:

- `01_исходная_панорама_1.jpg`
- `02_исходная_панорама_2.jpg`
- `03_чистая_панорама_эталон.jpg`
- `04_вид_с_кровати_эталон.jpg`
