## Как читать список

- **Приоритет** — исходная важность задачи.
- **Балл** — исполняемый приоритет с учётом срока, полезности, длительности, зависимостей и удобства совмещения.
- A ≥80 — запускать сейчас; B 65–79 — следующий блок; C 50–64 — по пути или при свободном окне; D <50 — отложить или перепроверить необходимость.
- Покупка компонентов означает только «проект готов к выполнению», а не обязательный немедленный монтаж.
- Шумные и пыльные работы желательно закончить до 24.08; общий предел текущего домашнего цикла — 31.08.

## Ключевые цепочки

- Роддом: `B-002 → покупки → B-003 → B-004`; параллельно `B-005`, `B-006`.
- Малыш: `B-001 → покупки → B-007/B-008/B-009/B-010`.
- Электрика: `V-002 + схема → DER-ELEC-001 → BUY-011 → единый монтажный блок`.
- Плиссе: `S-005 → BUY-010 → доставка → S-006`.
- Панно: `PAN-001 + PAN-002 → PAN-004 → PAN-005 → PAN-006 → PAN-007`; параллельно `PAN-003 → PAN-008`; затем `PAN-009`.
- Отделка спальни: заказы и проверки `BED-001/003/005/007/008/011 → покупки → монтаж BED-004/006/010/013 → BED-014`.
- Кладовая: `W-001 → W-002 → BUY-STOR-001 → W-006`.
