◆ sam3x_watchdog_boot_recovery_from_watchdog_reset()

void sam3x_watchdog_boot_recovery_from_watchdog_reset ( void )

Выполняет раннее восстановление после watchdog-reset.

Если последний reset был вызван watchdog, функция один раз выполняет software reset процессора и периферии через RSTC. Это принудительно переинициализирует USB-периферию после watchdog-события.

◆ sam3x_watchdog_disable_before_enable()

void sam3x_watchdog_disable_before_enable ( void )

Отключает watchdog до первой конфигурации WDT_MR.

Функция оставлена для сервисных сборок без watchdog. В диагностической baseline-прошивке она не вызывается.

◆ sam3x_watchdog_enable()

void sam3x_watchdog_enable ( const Sam3xWatchdogConfig * config)

Включает watchdog.

Регистр WDT_MR записывается один раз после аппаратного сброса. До вызова этой функции код не должен записывать WDT_MR.
