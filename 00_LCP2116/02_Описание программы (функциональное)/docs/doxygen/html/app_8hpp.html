Подробное описание

Прикладной интерфейс жизненного цикла диагностической прошивки.

Файл объявляет две функции верхнего уровня, вызываемые из main.cpp. Функции сохраняют привычную семантику и оформлены как собственный прикладной интерфейс проекта.

Функции

◆ loop()

void loop ( void )

Выполняет основной циклический алгоритм baseline-прошивки LCP.

Функция обслуживает heartbeat, RS-485 echo, SC16IS echo, W5500 echo, microSD, контроль батареи, RTC, USB service console и watchdog feed.

◆ setup()

void setup ( void )

Выполняет однократную инициализацию baseline-прошивки LCP.

Функция инициализирует board-слой, платформенные интерфейсы, SPI, USB service console, диагностические модули, RTC и watchdog.
