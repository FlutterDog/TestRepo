30/**
31 * @brief Загружает baud.TXT и Parity.TXT поверх текущих значений.
32 *
33 * Первая значимая строка каждого файла содержит количество значений `4`.
34 * Далее идут параметры физических портов S1, S2, S3 и S4. Завершающая строка
35 * `fin` и комментарии после `//` поддерживаются общим SD-парсером.
36 *
37 * `baud.TXT` содержит реальные значения скорости. `Parity.TXT` принимает
38 * только штатные коды: `0=None`, `1=Odd`, `2=Even`. Файлы применяются
39 * независимо: ошибка одного файла не отменяет корректные данные другого.
40 *
41 * @param[in,out] configs Текущие параметры портов; корректные файлы заменяют
42 * только соответствующую группу значений.
43 * @param[out] report Результаты чтения обоих файлов.
44 */
45void field_serial_config_load(
46 LcpFieldPortConfig configs[LCP_FIELD_PORT_COUNT],
47 FieldSerialConfigReport* report);
