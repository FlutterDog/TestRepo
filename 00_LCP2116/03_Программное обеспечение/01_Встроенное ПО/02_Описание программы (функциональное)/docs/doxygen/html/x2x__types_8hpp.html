Подробное описание

Типы данных модулей внутренней шины X2X контроллера LCP.

Числовые идентификаторы устройств являются частью формата X2X.TXT. После выпуска прошивки назначенное значение ID нельзя переиспользовать или изменять, иначе существующие конфигурационные файлы потеряют смысл.
