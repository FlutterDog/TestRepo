Подробное описание

Машинный USB CDC-протокол чтения и записи конфигурации LCP2116.

Header-only реализация включается только из app.cpp. Это позволяет оставить проект Microchip Studio без отдельной translation unit. Обычная текстовая консоль продолжает работать на том же USB CDC-порту. Бинарный режим активируется кадром, начинающимся с нулевого байта и сигнатуры "LCP".
