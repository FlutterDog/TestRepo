◆ x2x_config_load()

X2XConfigResult x2x_config_load ( const char * file_name,
X2XConfig & config,
X2XConfigError & error )

Загружает и полностью проверяет X2X.TXT.

Первая содержательная строка — количество модулей, следующие строки — числовые ID. Поддерживаются пустые строки, комментарии // и необязательная завершающая строка Fin. Порядок ID задаёт slave address.

Аргументы
[in]file_nameКаноническое имя в корневом каталоге microSD.
[out]configРезультирующая конфигурация, изменяемая только при успехе.
[out]errorПодробности результата.
Возвращает
Код результата.
