Подробное описание

Прикладные параметры одного экземпляра демонстрационного прибора.

Структура копируется в runtime при initialize_runtime(). Изменение исходного массива g_configs во время активной транзакции запрещено; reload сначала ждёт, пока все четыре master станут idle.
