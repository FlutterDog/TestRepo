◆ vApplicationTickHook()

void vApplicationTickHook ( void )

Обслуживает платформенное время из обработчика тика FreeRTOS.

FreeRTOS вызывает эту функцию один раз на каждый системный тик. При частоте 1 кГц функция увеличивает миллисекундный счётчик и сохраняет обслуживание отложенного перехода в ROM-загрузчик SAM-BA по команде 1200 baud.
