Подробное описание

Неблокирующий Modbus RTU master для одного half-duplex порта.

Один объект обслуживает только одну транзакцию одновременно. Для нескольких физических UART создаётся отдельный ModbusRtuMaster на каждый transport. Объект не владеет transport и пользовательским FC03-буфером: оба должны жить до завершения транзакции.
