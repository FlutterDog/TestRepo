◆ hal_spi_begin()

void hal_spi_begin ( void )

Инициализирует SPI0 в режиме master.

Функция настраивает линии MISO, MOSI и SCK на периферийную функцию SPI0. Линии Chip Select управляются прикладным кодом через GPIO.
