◆ modbus_rtu_crc_self_test()

uint8_t modbus_rtu_crc_self_test ( void )

Проверяет реализацию CRC по известному Modbus RTU кадру.

Контрольные данные: 01 03 00 00 00 01, ожидаемое значение CRC 0x0A84, передаваемые байты 84 0A.

Возвращает
1 при успешной проверке, иначе 0.
