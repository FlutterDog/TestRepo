Подробное описание

Состояние драйвера отдельного экземпляра модуля.

Runtime хранится отдельно от данных устройства, чтобы общая структура X2XDeviceHeader отражала состояние связи, а многошаговая машина драйвера не загрязняла пользовательские данные конкретного типа.
