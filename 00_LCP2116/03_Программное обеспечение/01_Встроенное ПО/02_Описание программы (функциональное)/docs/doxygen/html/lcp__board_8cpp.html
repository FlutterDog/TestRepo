◆ lcp_board_init_gpio()

void lcp_board_init_gpio ( void )

Инициализирует дискретные линии платы LCP Basic.

Функция задаёт направления GPIO, исходные состояния линий Chip Select, светодиодных выходов и линий управления приёмопередатчиками RS-485.

См. определение в файле lcp_board.cpp строка 8

Перекрестные ссылки delay(), digitalWrite(), LCP_PIN_A0, LCP_PIN_A7, LCP_PIN_ETH1_CS, LCP_PIN_ETH2_CS, LCP_PIN_MICROSD_CS, LCP_PIN_PLC_OK, LCP_PIN_RS485_DE_0, LCP_PIN_RS485_DE_1, LCP_PIN_RS485_DE_2, LCP_PIN_RS485_DE_3, LCP_PIN_SD_OK, LCP_PIN_UART1_CS, LCP_PIN_UART2_CS, LCP_PIN_UART3_CS, LCP_PIN_WIZ_INT, LCP_PIN_X2X_LED, LCP_PIN_X2X_TRANSMIT, LCP_RS485_RECEIVE, LCP_RS485_TRANSMIT и pinMode().

Используется в setup().
