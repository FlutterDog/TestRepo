Подробное описание

Минимальный SPI/FAT16/FAT32 слой microSD контроллера LCP.

Слой работает только с корневым каталогом и короткими именами FAT 8.3. Он не выделяет динамическую память и вызывается последовательно из одной прикладной задачи FreeRTOS.

◆ LcpSdStorageResult

enum LcpSdStorageResult

Результат низкоуровневой операции с microSD.

Элементы перечислений
LCP_SD_STORAGE_OK 

Операция завершена успешно.

LCP_SD_STORAGE_NO_CARD 

Карта не отвечает на SPI.

LCP_SD_STORAGE_CARD_INIT_FAILED 

SD initialization sequence не завершена.

LCP_SD_STORAGE_VOLUME_UNSUPPORTED 

Раздел или FAT не поддерживается.

LCP_SD_STORAGE_FILE_NOT_FOUND 

Файл отсутствует в корневом каталоге.

LCP_SD_STORAGE_FILE_OPEN_FAILED 

Directory entry найден, но файл не открыт.

LCP_SD_STORAGE_FILE_EXISTS_ERROR 

Не удалось корректно заменить существующий файл.

LCP_SD_STORAGE_DIRECTORY_FULL 

В корневом каталоге нет свободной записи.

LCP_SD_STORAGE_NO_FREE_CLUSTER 

FAT не содержит свободного кластера.

LCP_SD_STORAGE_READ_FAILED 

Ошибка чтения блока или цепочки FAT.

LCP_SD_STORAGE_WRITE_FAILED 

Ошибка записи данных, FAT или directory entry.

LCP_SD_STORAGE_INVALID_NAME 

Имя не соответствует поддерживаемому FAT 8.3.

LCP_SD_STORAGE_NOT_READY 

Файловая система не смонтирована.
