Подробное описание

Неблокирующий fallback echo-test физической линии X2X.

S2–S4 сразу принадлежат FieldSensor и здесь не инициализируются. UART0 может оставаться echo только при пустой X2X-конфигурации. Приём ограничен 16 байтами за poll, частичный TX продолжается через tx_offset, а зависший TX сбрасывается по ограниченному timeout.

◆ rs485_echo_test_set_x2x_enabled()

void rs485_echo_test_set_x2x_enabled ( uint8_t enabled)

Передаёт или освобождает владение физической линией X2X.

При изменении владельца незавершённый echo-кадр сбрасывается, чтобы X2X master не получил остаток диагностического ответа.

Аргументы
[in]enabledНенулевое значение разрешает echo.
