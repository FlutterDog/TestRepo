◆ sd_config_load_int16()

SdConfigResult sd_config_load_int16 ( const char * file_name,
int16_t * output,
size_t capacity,
uint8_t * loaded_count )

Загружает знаковые 16-битные значения из числового TXT-файла.

Формат файла:

N
value_1
...
value_N
fin

Маркер fin необязателен. Пустые строки, UTF-8 BOM в начале файла и комментарии после // или # игнорируются.

Аргументы
[in]file_nameКаноническое имя файла в формате FAT 8.3.
[out]outputБуфер результата; output[0] получает количество N, значения размещаются в output[1..N].
[in]capacityКоличество элементов в output, включая output[0].
[out]loaded_countФактическое количество значений без output[0].
Возвращает
Код результата операции.

◆ sd_config_load_uint32()

SdConfigResult sd_config_load_uint32 ( const char * file_name,
uint32_t * output,
size_t capacity,
uint8_t * loaded_count )

Загружает беззнаковые 32-битные значения из числового TXT-файла.

Использует тот же формат, правила комментариев и необязательный маркер fin, что и sd_config_load_int16(). Функция предназначена, в частности, для реальных значений baudrate, которые не обязаны помещаться в int16_t.

Аргументы
[in]file_nameКаноническое имя файла в формате FAT 8.3.
[out]outputБуфер результата; output[0] получает количество N, значения размещаются в output[1..N].
[in]capacityКоличество элементов в output, включая output[0].
[out]loaded_countФактическое количество значений без output[0].
Возвращает
Код результата операции.
