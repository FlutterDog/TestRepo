Подробное описание

Минимальный неблокирующий Modbus TCP server для holding registers.

Protocol engine не зависит от W5500: вызывающий слой добавляет байты TCP, получает готовый ответ и самостоятельно выполняет физическую передачу.

◆ modbus_tcp_server_process()

uint8_t modbus_tcp_server_process ( ModbusTcpServer & server,
ModbusTcpReadHoldingHandler read_handler,
void * context )

Обрабатывает один полный ADU, если он накоплен в RX-потоке.

Пока tx_length не очищен вызовом modbus_tcp_server_response_sent(), новый запрос не обрабатывается. Это сохраняет сформированный ответ при временно занятом аппаратном TX-буфере.

Аргументы
[in,out]serverЭкземпляр соединения.
[in]read_handlerCallback прикладной карты holding-регистров.
[in]contextПользовательский контекст callback.
Возвращает
1, если сформирован ответ, иначе 0.
