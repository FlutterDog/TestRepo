Подробное описание

Диагностика card-detect, mount и базовых операций microSD.

Обычный poll не пишет на карту. Запись выполняется только явной командой sd test, которая перезаписывает отдельный файл SDTEST.TXT и не затрагивает X2X.TXT, baud.TXT, Parity.TXT или Ethernet-конфигурацию.

◆ sd_card_test_poll()

void sd_card_test_poll ( void )

Выполняет debounce detect и ограниченный по частоте повтор mount.

Вызов не ждёт появления карты. После извлечения готовность FAT сбрасывается, а после установки инициализация повторяется не чаще заданного retry period.
