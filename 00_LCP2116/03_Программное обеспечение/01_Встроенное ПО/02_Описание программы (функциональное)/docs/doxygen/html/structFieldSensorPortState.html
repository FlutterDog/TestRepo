Подробное описание

Runtime одного физического FieldSensor-порта.

Каждый S1..S4 имеет собственный ModbusRtuMaster, буфер, таймер и качество. Последние корректные registers не обнуляются при ошибке. Использовать их разрешено только при valid != 0; после пяти последовательных ошибок устанавливаются connection_lost=1 и valid=0.
