◆ __attribute__()

struct __attribute__ ( (packed, aligned(4)) )

Версия 1 бинарного payload внутреннего хранилища.

Поля имеют фиксированную ширину. Reserved заполняется нулями и оставляет пространство для совместимых дополнений без немедленного увеличения записи. Выравнивание 4 гарантирует безопасный доступ к uint32_t на Cortex-M3.

< 0=8N1, 1=8O1, 2=8E1.
