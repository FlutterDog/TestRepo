Подробное описание

Абстрактный байтовый transport одного Modbus RTU-порта.

Все callback обязаны относиться к одному физическому half-duplex UART. write должен принять весь запрос за один вызов либо вернуть меньше длины; частичный запрос считается transport error. tx_idle означает физическое окончание передачи последнего stop-bit, а не только пустой software buffer.
