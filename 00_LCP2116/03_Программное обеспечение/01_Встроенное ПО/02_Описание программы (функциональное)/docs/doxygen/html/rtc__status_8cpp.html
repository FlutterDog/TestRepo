Подробное описание

Неблокирующая диагностика и настройка локального RTC ATSAM3X8E.

Команда rtc set только запускает аппаратную последовательность обновления. ACKUPD, запись регистров, проверка результата и timeout обслуживаются из rtc_status_poll(), не останавливая X2X, FieldSensor или Ethernet.

При добавлении формата даты изменяйте только parse_datetime_value(). Аппаратную state machine следует оставлять в hal/sam3x_rtc.*.

◆ rtc_status_handle_command()

uint8_t rtc_status_handle_command ( const char * command)

Обрабатывает time, rtc, rtc time и rtc set ....

Формат установки: YYYY-MM-DD HH:MM:SS; также принимаются двухзначный год, разделитель точки и буква T. Фактическое завершение проверяется командами time либо rtc после последующих poll-вызовов.

Аргументы
[in]commandНормализованная строка нижнего регистра без CR/LF.
Возвращает
1 для распознанной RTC-команды, иначе 0.

◆ rtc_status_poll()

void rtc_status_poll ( void )

Продвигает RTC update state machine и контролирует общий timeout.

Функция не ожидает ACKUPD в цикле и должна вызываться на каждом проходе основной прикладной задачи.
