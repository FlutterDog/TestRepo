◆ ethernet_network_config_load()

void ethernet_network_config_load ( W5500NetworkConfig configs[LCP_ETHERNET_COUNT],
EthernetNetworkConfigReport reports[LCP_ETHERNET_COUNT] )

Загружает только канонические файлы установленного проекта.

ETH1: MAC.txt, IP.txt, SUBNET.txt, GATE.txt
ETH2: MAC2.txt, IP2.txt, SUBNET2.txt, GATE2.txt

Каждый файл применяется независимо. Ошибка одного параметра сохраняет его текущее значение, но не блокирует корректные файлы того же интерфейса. Псевдонимы и альтернативные имена намеренно не поддерживаются.

Аргументы
[in,out]configsТекущие настройки; корректные файлы заменяют поля.
[out]reportsОтчёты ETH1 и ETH2.
