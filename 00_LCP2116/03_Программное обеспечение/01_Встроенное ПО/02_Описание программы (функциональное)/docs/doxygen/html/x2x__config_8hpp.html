◆ X2XConfigResult

enum X2XConfigResult : uint8_t

Результат загрузки или применения конфигурации X2X.

Элементы перечислений
X2X_CONFIG_OK 

Конфигурация проверена и применима.

X2X_CONFIG_STORAGE_NOT_READY 

microSD ещё не доступна.

X2X_CONFIG_FILE_NOT_FOUND 

X2X.TXT отсутствует.

X2X_CONFIG_FILE_OPEN_FAILED 

Файл найден, но не открыт.

X2X_CONFIG_EMPTY_FILE 

Не найдено количество модулей.

X2X_CONFIG_INVALID_COUNT 

Количество вне диапазона 0..X2X_MAX_MODULES.

X2X_CONFIG_LINE_TOO_LONG 

Физическая строка превышает предел парсера.

X2X_CONFIG_INVALID_VALUE 

Строка не является допустимым целым числом.

X2X_CONFIG_INVALID_DEVICE_ID 

ID отсутствует или запрещён каталогом.

X2X_CONFIG_INCOMPLETE_FILE 

Типов меньше заявленного количества.

X2X_CONFIG_EXTRA_DATA 

После ожидаемых типов найдены лишние данные.

X2X_CONFIG_APPLY_PENDING 

Применение отложено до безопасной точки.

X2X_CONFIG_REGISTRY_BUILD_FAILED 

Каталог не смог построить runtime-реестр.

◆ x2x_config_load()

X2XConfigResult x2x_config_load ( const char * file_name,
X2XConfig & config,
X2XConfigError & error )

Загружает и полностью проверяет X2X.TXT.

Первая содержательная строка — количество модулей, следующие строки — числовые ID. Поддерживаются пустые строки, комментарии // и необязательная завершающая строка Fin. Порядок ID задаёт slave address.

Аргументы
[in]file_nameКаноническое имя в корневом каталоге microSD.
[out]configРезультирующая конфигурация, изменяемая только при успехе.
[out]errorПодробности результата.
Возвращает
Код результата.
