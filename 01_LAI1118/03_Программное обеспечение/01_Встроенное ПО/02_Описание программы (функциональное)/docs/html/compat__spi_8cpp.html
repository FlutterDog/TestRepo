Подробное описание

SPI master-драйвер для ATmega328P.

Реализация используется для обмена с внешними SPI-регистрами платы LAI.

Настройки интерфейса:

  • режим ведущего;
  • SPI mode 0;
  • передача старшим битом вперёд;
  • частота SCK = F_CPU / 16.
