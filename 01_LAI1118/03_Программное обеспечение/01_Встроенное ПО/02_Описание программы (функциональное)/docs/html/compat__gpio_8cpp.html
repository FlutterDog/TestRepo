Подробное описание

Реализация базовых GPIO-операций HAL для ATmega328P.

Файл реализует функции:

  • hal::pinMode();
  • hal::digitalWrite();
  • hal::digitalRead().

Используется проектная нумерация цифровых линий:

  • 0..7 -> PORTD, bit 0..7;
  • 8..13 -> PORTB, bit 0..5;
  • 14..19 -> PORTC, bit 0..5.

Аппаратные сигналы конкретной платы должны обслуживаться через board-слой. Этот файл предоставляет только универсальные операции GPIO.

Заметки
PC6 / RESET не входит в поддерживаемую карту GPIO.
Для неподдерживаемых номеров пинов операции не выполняются.
Предупреждения
Изменение PORTx/DDRx выполняется через read-modify-write. Если один и тот же порт изменяется из основного кода и ISR, вызывающий код должен обеспечить синхронизацию доступа.
