◆ delayMicroseconds()

void hal::delayMicroseconds ( uint16_t us)

Выполняет блокирующую задержку в микросекундах.

Аргументы
usДлительность задержки в микросекундах.

Задержка построена на _delay_loop_2(). Один цикл _delay_loop_2(N) занимает приблизительно 4 * N тактов CPU.

Для F_CPU = 16000000 Гц используется 4 итерации на 1 мкс.

Предупреждения
Точность функции зависит от F_CPU, оптимизации компилятора и накладных расходов на вызов функции и цикл.

См. определение в файле compat_tick.cpp строка 160

164

167 return;
168 }
169
170 while (us-- != 0u)
171 {
172 _delay_loop_2(iters_per_us);

◆ pinMode()

void hal::pinMode ( uint8_t p,
PinMode mode )

Настраивает режим GPIO-линии.

Аргументы
pПроектный номер пина.
modeРежим линии:
  • INPUT — вход без внутренней подтяжки;
  • OUTPUT — цифровой выход;
  • INPUT_PULLUP — вход с внутренней подтяжкой к Vcc.

Поведение режимов:

  • OUTPUT: соответствующий бит DDRx устанавливается в 1;
  • INPUT: бит DDRx сбрасывается, бит PORTx сбрасывается;
  • INPUT_PULLUP: бит DDRx сбрасывается, бит PORTx устанавливается.

Для неподдерживаемых номеров пинов функция не выполняет действий.
