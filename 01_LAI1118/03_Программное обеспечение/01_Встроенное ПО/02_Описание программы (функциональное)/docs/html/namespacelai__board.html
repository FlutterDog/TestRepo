◆ initIo()

void lai_board::initIo ( void )

Инициализирует линии GPIO платы LAI.

Функция настраивает линии RS-485, выбор SPI-регистров, разрешение сдвиговых регистров, адресные входы с внутренними подтяжками и светодиод состояния связи.

127 * PD3 — выбор SPI-регистра светодиодов.
128 * PD4 — выбор SPI-регистра режимов аналоговых входов.
129 * PD5 — разрешение сдвиговых регистров.
130 */
131 DDRD |= static_cast<uint8_t>(

160 s_rs485TransmitMode = 0U;
161 }

◆ readSlaveAddress()

uint8_t lai_board::readSlaveAddress ( void )

Считывает аппаратный адрес платы.

Адрес формируется по пяти адресным входам ADDR0...ADDR4. Вход с низким уровнем считается установленным битом адреса.

Возвращает
Значение аппаратного адреса в диапазоне 0...31.
