Подробное описание

Публичный интерфейс прикладного уровня LAI.

Файл объявляет функции жизненного цикла прикладной программы:

  • setup() — однократная инициализация после старта микроконтроллера;
  • loop() — основной циклический обработчик.

Реализация прикладной логики находится в app.cpp.

◆ setup()

void setup ( void )

Выполняет однократную инициализацию приложения.

Функция вызывается один раз после старта микроконтроллера. Внутри выполняется настройка аппаратного слоя платы, интерфейсов обмена, прикладных параметров, Modbus RTU и начальных состояний модуля.
