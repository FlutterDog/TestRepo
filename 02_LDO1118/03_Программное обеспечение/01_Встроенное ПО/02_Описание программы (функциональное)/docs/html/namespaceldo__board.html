◆ BoardRevision

enum ldo_board::BoardRevision

Аппаратные ревизии платы LDO.

Ревизия определяет назначение линии управления RS-485 и карту релейных выходов.

Элементы перечислений
BOARD_OLD_RS485_PB2 

Ревизия платы с управлением RS-485 на PB2.

В этой ревизии:

  • RS-485 DE/RE подключён к PB2;
  • релейные выходы подключены к PD2...PD7, PB0, PB1.
BOARD_NEW_RS485_PD2 

Ревизия платы с управлением RS-485 на PD2.

В этой ревизии:

  • RS-485 DE/RE подключён к PD2;
  • релейные выходы подключены к PD3...PD7, PB0, PB1, PB2.

◆ initIo()

void ldo_board::initIo ( void )

Инициализирует аппаратные линии платы LDO.

Инициализирует аппаратные линии платы.

Настраивает:

  • светодиод статуса;
  • входы адресного переключателя;
  • линию управления RS-485;
  • релейные выходы.

После инициализации релейные выходы сбрасываются в ноль, а RS-485 переводится в режим приёма.

◆ readSlaveAddress()

uint8_t ldo_board::readSlaveAddress ( void )

Считывает Modbus-адрес с адресного переключателя.

Считывает адрес устройства с аппаратного адресного переключателя.

Возвращает
Modbus-адрес устройства.

Соответствие входов и битов адреса:

  • PC5 -> bit 0, 0b00000001;
  • PC4 -> bit 1, 0b00000010;
  • PC3 -> bit 2, 0b00000100;
  • PC2 -> bit 3, 0b00001000;
  • PC1 -> bit 4, 0b00010000.

Если все входы равны нулю, возвращается адрес 1.

Возвращает
Modbus-адрес устройства.

Если все биты адресного переключателя равны нулю, возвращается адрес 1.

См. определение в файле ldo_board.cpp строка 162

168 if ((PINC & _BV(PC3)) != 0u) { addr |= 0x04u; }
169 if ((PINC & _BV(PC2)) != 0u) { addr |= 0x08u; }

◆ relaysWrite()

void ldo_board::relaysWrite ( uint8_t state)

Записывает состояние релейных выходов.

Аргументы
stateБитовое состояние релейных выходов.

Ревизия BOARD_OLD_RS485_PB2:

  • bit 0 -> PB1;
  • bit 1 -> PB0;
  • bit 2 -> PD7;
  • bit 3 -> PD6;
  • bit 4 -> PD5;
  • bit 5 -> PD4;
  • bit 6 -> PD3;
  • bit 7 -> PD2.

Ревизия BOARD_NEW_RS485_PD2:

  • bit 0 -> PB2;
  • bit 1 -> PB1;
  • bit 2 -> PB0;
  • bit 3 -> PD7;
  • bit 4 -> PD6;
  • bit 5 -> PD5;
  • bit 6 -> PD4;
  • bit 7 -> PD3.
Аргументы
stateБитовое состояние релейных выходов.

Соответствие битов физическим линиям зависит от выбранной ревизии платы.
