Подробное описание

Проектный SPI-интерфейс поверх HAL.

Заголовок предоставляет:

  • константы порядка передачи битов;
  • класс SPISettings для хранения параметров SPI-обмена;
  • класс SPIClass для инициализации SPI и передачи байтов;
  • глобальный объект SPI.

Низкоуровневая работа с периферией выполняется функциями hal::spi_init() и hal::spi_txrx().

Заметки
В текущей реализации параметры SPISettings сохраняются в объекте, но не применяются при настройке аппаратного SPI. Если в проекте потребуется несколько SPI-устройств с разными режимами обмена, драйвер SPI необходимо расширить.
