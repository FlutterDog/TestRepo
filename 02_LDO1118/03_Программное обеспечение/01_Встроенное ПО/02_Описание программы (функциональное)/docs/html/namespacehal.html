void hal::delayMicroseconds ( uint16_t us)

Выполняет блокирующую задержку в микросекундах.

Аргументы
usДлительность задержки в микросекундах.

Задержка построена на _delay_loop_2(). Один цикл _delay_loop_2(N) занимает приблизительно 4 * N тактов CPU.

Для F_CPU = 16000000 Гц используется 4 итерации на 1 мкс.

Предупреждения
Точность функции зависит от F_CPU, оптимизации компилятора и накладных расходов на вызов функции и цикл.

Аргументы
pПроектный номер пина.
hitrue — установить логическую единицу; false — установить логический ноль.

Для линии, настроенной как OUTPUT, функция задаёт выходной уровень. Для линии, настроенной как INPUT, запись в PORTx управляет внутренней подтяжкой:

  • true — подтяжка включена;
  • false — подтяжка отключена.

Для неподдерживаемых номеров пинов функция не выполняет действий.

◆ pinMode()

void hal::pinMode ( uint8_t p,
PinMode mode )

Настраивает режим GPIO-линии.

Аргументы
pПроектный номер пина.
modeРежим линии:
  • INPUT — вход без внутренней подтяжки;
  • OUTPUT — цифровой выход;
  • INPUT_PULLUP — вход с внутренней подтяжкой к Vcc.

Поведение режимов:

  • OUTPUT: соответствующий бит DDRx устанавливается в 1;
  • INPUT: бит DDRx сбрасывается, бит PORTx сбрасывается;
  • INPUT_PULLUP: бит DDRx сбрасывается, бит PORTx устанавливается.

Для неподдерживаемых номеров пинов функция не выполняет действий.

См. определение в файле compat_gpio.cpp строка 138

139 {
140 const PinDesc d = resolve(p);
141
142 if (!d.valid)
143 {
144 return;
145 }
146
147 const uint8_t mask = bitMask(d.bit);
148
149 if (mode == OUTPUT)
150 {
151 *d.ddr |= mask;
152 return;
153 }
154
155 *d.ddr &= static_cast<uint8_t>(~mask);
156
157 if (mode == INPUT_PULLUP)
158 {
159 *d.port |= mask;
160 }

◆ tick_init()

void hal::tick_init ( void )

Инициализирует системный миллисекундный тикер.

Настраивает Timer0:

  • режим CTC;
  • предделитель 64;
  • сравнение по OCR0A;
  • прерывание TIMER0_COMPA_vect.

Для F_CPU = 16000000 Гц: 16000000 / 64 / (249 + 1) = 1000 Гц.

См. определение в файле compat_tick.cpp строка 79

81 TCCR0A = static_cast<uint8_t>(_BV(WGM01));

83 OCR0A = 249u;
84 TIMSK0 = static_cast<uint8_t>(_BV(OCIE0A));
85 }

Используется в main().
