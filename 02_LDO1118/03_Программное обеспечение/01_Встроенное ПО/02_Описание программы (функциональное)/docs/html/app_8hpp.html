Подробное описание

Публичный интерфейс прикладного уровня LDO.

Заголовок объявляет функции жизненного цикла приложения:

  • setup() — однократная инициализация после старта микроконтроллера;
  • loop() — основной циклический обработчик.

Внутренняя логика приложения, карта Modbus-регистров, управление реле, адресным переключателем, аппаратной картой платы и переходом в bootloader реализованы в app.cpp и связанных модулях.

◆ setup()

void setup ( void )

Выполняет однократную инициализацию приложения LDO.

Функция вызывается один раз из main().

Выполняет:

  • настройку watchdog;
  • инициализацию аппаратных линий платы;
  • чтение адресного переключателя;
  • инициализацию Modbus RTU по RS-485;
  • начальную установку программных таймеров.
