Подробное описание

Общий HAL и базовые системные объявления для восьмибитных AVR.

Заголовок предоставляет:

  • базовые проектные типы byte, word, boolean;
  • константы формата кадра UART SERIAL_*;
  • служебные функции ограничения и линейного отображения значений;
  • пространство имён hal для низкоуровневых аппаратных вызовов;
  • минимальный потоковый интерфейс SerialPort поверх UART0;
  • короткие inline-обёртки для часто используемых системных операций.
Заметки
Для корректной работы таймингов значение F_CPU должно соответствовать фактической частоте тактирования микроконтроллера.
Предупреждения
Этот файл не должен содержать карту выводов конкретной платы. Назначение прикладных сигналов описывается в аппаратном слое платы.
