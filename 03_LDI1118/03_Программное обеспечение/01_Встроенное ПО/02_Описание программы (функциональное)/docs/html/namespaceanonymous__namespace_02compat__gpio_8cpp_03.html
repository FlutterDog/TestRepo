◆ resolve()

PinDesc anonymous_namespace{compat_gpio.cpp}::resolve ( uint8_t p)
inlinestatic

Сопоставляет проектный номер пина с портом ATmega328P.

Аргументы
pПроектный номер пина.
Возвращает
Дескриптор пина.

Таблица соответствия:

  • p = 0..7: PORTD, bit = p;
  • p = 8..13: PORTB, bit = p - 8;
  • p = 14..19: PORTC, bit = p - 14.

Для неподдерживаемых номеров возвращается дескриптор с valid == false.
