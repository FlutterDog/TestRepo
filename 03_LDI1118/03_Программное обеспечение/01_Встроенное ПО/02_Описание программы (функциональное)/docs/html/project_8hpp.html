Подробное описание

Общие настройки сборки проекта LDI.

Файл задаёт базовые параметры проекта и подключает общий аппаратный слой.

Здесь должны находиться только настройки, общие для всей прошивки:

  • частота тактирования микроконтроллера;
  • базовые системные типы;
  • подключение общего HAL.

Файл не должен содержать:

  • прикладную логику;
  • карту Modbus-регистров;
  • EEPROM-карту;
  • глобальные переменные приложения;
  • карту выводов платы;
  • настройки конкретных аппаратных линий.

Аппаратная карта LDI находится в ldi_board.hpp / ldi_board.cpp.
