◆ initIo()

void ldi_board::initIo ( void )

Инициализирует аппаратные линии платы LDI.

Настраивает:

  • входы адресного переключателя;
  • линии UART/RS-485;
  • линии 74HC165;
  • линии 74HC595;
  • светодиод состояния связи.

После инициализации:

  • RS-485 переводится в режим приёма;
  • LED-панель сбрасывается в ноль;
  • светодиод состояния связи выключается.

294 /*
295 * Адресный переключатель: PC0...PC4, входы с внутренней подтяжкой.
296 * Переключатели активны низким уровнем.
297 */
298 DDRC &= static_cast<uint8_t>(~ADDRESS_INPUTS_MASK);
299 PORTC |= ADDRESS_INPUTS_MASK;
300
301 /*
302 * UART/RS-485:
303 * - PD0 RXD, вход без внутренней подтяжки;
304 * - PD1 TXD, выход;
305 * - PD2 DE/RE, выход, начально режим приёма.
306 */
307 DDRD &= static_cast<uint8_t>(~_BV(PD0));
308 DDRD |= static_cast<uint8_t>(_BV(PD1) | RS485_DE_MASK);
309
310 PORTD &= static_cast<uint8_t>(~_BV(PD0));
311 PORTD &= static_cast<uint8_t>(~_BV(PD1));
312 rs485ReceiveMode();
313
314 /*
315 * Сдвиговые регистры:
316 * - PD3 latch, выход;
317 * - PD4 clock, выход;
318 * - PD5 data from 74HC165, вход без внутренней подтяжки;
319 * - PB1 data to 74HC595, выход.
320 */
321 DDRD |= static_cast<uint8_t>(SR_LATCH_MASK | SR_CLOCK_MASK);
322 DDRD &= static_cast<uint8_t>(~SR_INPUT_DATA_MASK);
323

326 PORTD &= static_cast<uint8_t>(~SR_INPUT_DATA_MASK);

333 */

uint16_t ldi_board::readInputs ( void )

Считывает состояние шестнадцати дискретных входов.

Возвращает
Битовое состояние входов.
Битовое состояние входов.

Чтение выполняется через последовательный выход 74HC165. Первый считанный бит помещается в bit 15 результата, последний считанный бит помещается в bit 0 результата.

Логическая единица на выходе 74HC165 записывается как 1 в соответствующий бит результата.

Заметки
Линии latch и clock общие для 74HC165 и 74HC595. Поэтому после чтения входов аппаратный слой восстанавливает последнее состояние LED-панели.

◆ readSlaveAddress()

uint8_t ldi_board::readSlaveAddress ( void )

Считывает Modbus-адрес с аппаратного адресного переключателя.

Возвращает
Modbus-адрес устройства.
Modbus-адрес устройства.

Адресный переключатель подключён к PC0...PC4. Входы работают с внутренними подтяжками к Vcc. Активное положение переключателя даёт логический ноль на входе.

После инверсии и зеркального разворота битов соответствие такое:

  • PC4 -> bit 0, 0b00000001;
  • PC3 -> bit 1, 0b00000010;
  • PC2 -> bit 2, 0b00000100;
  • PC1 -> bit 3, 0b00001000;
  • PC0 -> bit 4, 0b00010000.

Если считанное значение равно нулю, возвращается адрес 1.

См. определение в файле ldi_board.cpp строка 348

349 {
350 /*
351 * Входы подтянуты к Vcc, активное положение переключателя даёт ноль.
352 * Поэтому состояние входов инвертируется.
353 */
354 const uint8_t raw =
355 static_cast<uint8_t>((~PINC) & ADDRESS_INPUTS_MASK);
356
357 uint8_t addr = mirrorFiveBits(raw);
358
359 if (addr == 0u)
360 {
361 addr = 1u;
362 }
363
364 return addr;
365 }
