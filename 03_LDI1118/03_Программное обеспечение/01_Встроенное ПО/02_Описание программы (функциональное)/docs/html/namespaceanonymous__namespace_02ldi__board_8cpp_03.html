◆ capture165Inputs()

void anonymous_namespace{ldi_board.cpp}::capture165Inputs ( void )

Выполняет захват состояния параллельных входов 74HC165.

Для 74HC165 линия SH/LD активна низким уровнем. Последовательность:

  • перевод линии в высокий уровень;
  • кратковременный низкий уровень для загрузки параллельных входов;
  • возврат в высокий уровень для последовательного сдвига.

См. определение в файле ldi_board.cpp строка 188

190 PORTD |= SR_LATCH_MASK;
191 ioNop();
192
193 PORTD &= static_cast<uint8_t>(~SR_LATCH_MASK);
194 ioNop();
195
196 PORTD |= SR_LATCH_MASK;
197 ioNop();
198 }
